# 부모님 폰 에이전트 — 비행기 모드 진단이 앱 로그에 안 보이는 문제 수정 (Claude Sonnet 5.5, Baze 경유)

작업 디렉터리: ~/workspace/repos/parents-phone-agent. 너는 Claude Sonnet 5.5다.

## 배경
- 2026-11-15 재테스트: 와이파이는 수정돼서 잘 됨 (확인됨). 비행기 모드는 여전히 실패.
- 직전 수정에서 `setSwitchInSettings`가 결과 종류(`SwitchAttempt`: 못 찾음/못 누름/눌렀지만 안 바뀜 등)와 "문구 N곳 발견, 화면 전체 스위치 M개" 진단을 `RestoreAttempt.method`에 담게 했다. 그런데 앱의 "고친 기록"에 그 내용이 안 보인다.

## 원인 (확인된 것)
- `CheckRunner.logLine()`이 `"${a.key.label}: ${a.before.display()} → ${a.after.display()} (${a.result.text})"`만 만들고 `a.method`를 빼먹는다. 그래서 진단이 로그에 남지 않는다.
- 에스컬레이션 메시지(`Escalation.kt` 59행)에는 method가 들어가지만, 텔레그램이 설정돼 있지 않아 사용자는 그 메시지를 볼 수 없다. 그래서 앱 로그에 method가 보이는 것이 유일한 확인 경로다.

## 할 일
1. `logLine()`에 method를 포함시켜서 "고친 기록"에 진단이 보이게 한다. 읽기 좋은 형식으로 (예: `비행기 모드: 켜짐 → 켜짐 (실패) — 접근성 설정 화면 스위치 (스위치를 못 찾음: 문구 0곳 발견, 화면 전체 스위치 0개)`). 기존 로그 형식을 크게 바꾸지 말고, method가 없을 때는 지금과 같은 모양을 유지한다.
2. `logLine`을 다루는 테스트가 있으면 그에 맞게 보완한다. 없으면 간단한 테스트를 추가한다 (method가 포함되는지).
3. 전체 단위 테스트를 통과시키고 빌드한다 (아래 빌드 명령 참조). 빌드 전 aapt dump badging으로 versionCode=1 / versionName=0.1.0-stage1 확인.

- 서명 설정(app/debug.keystore 고정, app/build.gradle.kts)은 건드리지 않는다.
- 커밋·푸시는 하지 않는다.
