# 런처 아이콘 적용 요청 (Baze Sonnet 5.5)

## 배경
- 앱 "폰 도우미"(`com.hyundo.parentsagent`)에 런처 아이콘이 없다. 현재 `AndroidManifest.xml`이 시스템 기본 아이콘(`@android:drawable/sym_def_app_icon`)을 쓰고 있다.
- 현도가 선택한 아이콘: 웃는 폰 캐릭터 + 위쪽 하트, 따뜻한 주황 배경 (도우미 느낌). 원본 파일: 프로젝트 루트의 `app-icon-source.webp` (1600x1600, RGB).
- 대상 프로젝트: `~/workspace/repos/parents-phone-agent/`

## 작업
1. `app-icon-source.webp`를 이용해 런처 아이콘을 만든다:
   - **어댑티브 아이콘 (API 26+ 우선)**: `res/mipmap-anydpi-v26/ic_launcher.xml` — foreground는 아이콘 아트워크, background는 아이콘 배경과 같은 단색(주황). 아트워크가 108dp 세이프 존 안에 들어가도록 크롭·배치할 것 (폰·하트가 잘리지 않게).
   - **레거시 폴백**: `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` (각 48/72/96/144/192px) + `ic_launcher_round.png` (원형 마스크용, 같은 소스에서 생성).
   - 아이콘 PNG는 소스 WebP에서 직접 변환한다 (외부 다운로드 금지, 오프라인 환경).
2. `AndroidManifest.xml`의 `android:icon`을 `@mipmap/ic_launcher`로, `android:roundIcon`을 `@mipmap/ic_launcher_round`로 바꾼다.
3. 앱 이름(`폰 도우미`)은 그대로 둔다.

## 검증 (반드시)
- 빌드 환경: `export JAVA_HOME=~/jdk-21`, `export PATH=$JAVA_HOME/bin:$PATH`, `export JAVA_TOOL_OPTIONS="-Djava.net.preferIPv6Addresses=true"`, `GRADLE_USER_HOME=/home/hatch/.gradle`, **`export LC_ALL=C.UTF-8 LANG=C.UTF-8`** (로케일이 POSIX면 한글 테스트명 때문에 Kotlin 컴파일이 실패한다).
- `./gradlew` 래퍼는 샌드박스에서 SSL 문제로 실패한다. 캐시된 바이너리를 직접 실행할 것: `/home/hatch/.gradle/wrapper/dists/gradle-8.10.2-bin/a04bxjujx95o3nb99gddekhwo/gradle-8.10.2/bin/gradle testDebugUnitTest assembleDebug --offline --no-daemon`
- 빌드가 "Timeout waiting to lock journal cache"로 실패하면 `gradle --stop` 후 잠깐 기다렸다가 재시도 (일시적 문제).
- 테스트 전부 통과(기존 115개) + 빌드 성공 + APK 생성 확인할 것.
- `aapt dump badging`으로 `application-icon`이 새 아이콘을 가리키는지 확인하고, APK에서 아이콘 PNG를 추출해 실제로 새 아이콘인지 육안으로 확인할 것.
- 작업이 끝나면 테스트 수와 변경된 파일 목록을 보고할 것.
