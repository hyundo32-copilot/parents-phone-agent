# UI 개선 2차 묶음 구현계획 1부 이어쓰기 (Claude Router 경유 Opus)

## 배경
바로 앞 요청에서 받은 1부 계획서가 토큰 한도(4096)에 걸려 아래 문장 중간에서 끊겼다. 끊긴 지점부터 이어서 써 준다. 앞부분을 반복하지 않는다.

끊긴 부분 (마지막 줄):
```
- **`core/LogPresentation.kt`** (순수 함수, Android 의존 없음)
  - `data class LogRow(val timeMillis: Long, val text: String, val count: Int)`
  - `fun collapseRepeats(items: List<T>, key: (T)->Any, time: (T)->Long, text: (T)`
```

앞부분에서 이미 정해진 결정 (바꾸지 않는다):
- P7: (나) `LogEntry`에 `kind`(FIXED/FAILED/INFO/DEV)와 `parentText` 추가. JSON 키 `k`/`p` 추가, 없으면 DEV/`null`. 부모님 영역은 FIXED/FAILED 항상, INFO는 parentText 있을 때만, DEV 제외. 최근 5건.
- P8: 표시할 때만 바로 이어지는 반복을 묶어 " (N번)" 표시.
- P25: 주색은 짙은 파랑 `#1565C0`. 상태 3색 초록 `#2E7D32` / 노랑 `#F9A825` + 검은 글씨 / 빨강 `#C62828`. 관리 버튼은 회색 테두리.
- P12: TILE 버튼(minHeight 112dp, 제목 27sp 굵게, 보조 20sp, 아이콘 32sp, 세로 전체 폭). `bigButton`은 TILE로 대체하고 삭제.
- P26: 구역마다 `Ui.card()` (모서리 16dp, 테두리 1dp `#E0E0E0`, 안쪽 여백 16dp, 카드 간격 12dp).
