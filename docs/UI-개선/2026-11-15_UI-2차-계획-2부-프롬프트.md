# UI 개선 2차 묶음 구현계획 2부 (Claude Router 경유 Opus) — 카드+TTS + 검증·작업 순서

## 당신의 역할
부모님 스마트폰 지킴이 앱 "폰 도우미"의 UI 개선 2차 묶음 중 **2부(결과를 카드+TTS로 + 검증 순서 + 작업 순서)**에 대한 구현계획을 작성한다. 코드를 직접 고치지 말고, 계획을 마크다운으로 작성해 돌려준다. 1부는 이미 다른 요청으로 받아서 계획이 완성됐다 — 이 요청에는 2부만 답한다.

## 앱과 현재 상태
- 앱: "폰 도우미" (`com.hyundo.parentsagent`), 안드로이드 단일 화면 앱. 부모님(70대 이상)이 쓰는 폰의 설정이 잘못 바뀌면 자동으로 되돌려 주는 앱이다.
- 화면은 코드로만 만든 프로그래매틱 View (XML·Compose 없음). `MainActivity.kt`가 `render()`로 화면 전체를 다시 그린다.
- UI 개선 1차 완료: 상단 상태 카드(초록/노랑/빨강), 순서 재배치, 가족·관리용 접기(2초 길게 눌러 열기), 취침 시간 선택기. 단위 테스트 141개 전부 통과.
- 현재 코드 (실측): `android/MainActivity.kt`(화면 전체), `android/Ui.kt`(도우미: `text`, `button`, `card`, `bigButton`, `statusCard`, `strip`, `collapsible`, `divider`), `android/Announcer.kt`(TTS 안내, 지금은 고치기 전 안내에만 사용, 한국어 음성 없으면 false 반환), `android/CheckRunner.kt`(점검 실행), `core/StatusCard.kt`·`core/LongPressGate.kt`(순수 함수 + 테스트).
- 토스트 사용처(`MainActivity.kt`): "다시 보내는 중이에요", "다시 자동으로 고칠게요", "기준을 저장했어요", "분류: …" 등 (전부 `Toast.LENGTH_LONG`).

## 2부 범위
**결과를 토스트 대신 카드+TTS로 (P19·P20) — 난이도 소~중**
- P19: TTS 활용 넓히기. (소) 상태 카드 길게 누르기 또는 카드 옆 [🔊 읽어 주기] 버튼 → 카드 문장 읽기 ("폰이 괜찮아요. 마지막 확인은 오후 3시 10분이에요."). (소) 점검이 끝나면 토스트만 띄우지 말고 결과 한 줄을 읽어 준다. (과함, 제외) 화면 전체 TTS — 시스템 TalkBack이 이미 한다. 각 뷰에 `contentDescription`을 잘 다는 정도만. 주의: 한국어 음성이 없으면 `Announcer`가 false — 그럴 때 화면 문구만으로 충분해야 한다.
- P20: "기준을 저장했어요", "분류: …" 등 결과가 토스트로만 나오는 것을 상태 카드 보조 줄이나 결과 카드에 다음 점검 전까지 남긴다. 토스트(`LENGTH_LONG` 3.5초)는 어르신이 다 못 읽는 경우가 많다.
- 결정이 필요한 점: [읽어 주기] 버튼을 둘지, 카드 길게 누르기로 할지 (둘 다인지), 결과 카드가 보여 주는 기간 (다음 점검 전까지 유지인지, 몇 초만인지), TTS가 실패했을 때의 표시. **결정을 내려 적을 것.**

## 2부 계획서에 들어갈 것
1. P19·P20 설계 결정 (위 결정 사항 포함) + 파일별 변경 목록 (함수·필드 이름 수준까지).
2. 테스트 계획: 새로 추가할 단위 테스트 (순수 함수는 `core/`에 두고 테스트를 붙인다). TTS는 실기 확인 항목으로 분리한다.
3. 검증 순서: 빌드·테스트 명령과 환경 주의사항 — Gradle 래퍼(`./gradlew`)는 샌드박스에서 SSL 문제로 실패하므로 캐시된 바이너리(`/home/hatch/.gradle/wrapper/dists/gradle-8.10.2-bin/a04bxjujx95o3nb99gddekhwo/gradle-8.10.2/bin/gradle testDebugUnitTest assembleDebug --offline --no-daemon`)를 쓰고, `LC_ALL=C.UTF-8 LANG=C.UTF-8`을 설정하고, "Timeout waiting to lock journal cache"가 나면 `gradle --stop` 후 재시도한다. APK 서명은 프로젝트 내 고정 키(`app/debug.keystore`)를 건드리지 않는다.
4. 작업 순서: 1부(P7·P8, P12·P25·P26)와 2부(P19·P20)를 합친 전체 작업 순서 (항목 간 의존 순서 포함).
5. 위험과 주의 (2부 관련): 실기 확인이 필요한 항목 (한국어 TTS 음성 유무·음질, TalkBack과의 충돌 여부, 결과 카드가 화면을 너무 길게 만드는지).
