- 대상 프로젝트: `~/workspace/repos/parents-phone-agent/`

## 구현 범위 (1차 묶음 — 제안서의 P1, P4, P21·P22·P23, P30)
1. **P1 순서 재배치 + P11 부모님 버튼 2개로** (난이도 소):
   - 새 순서: (고치는 중 배너, 상단 고정) → **상태 카드(P4)** → **큰 버튼 2개 [지금 점검하기]·[폰이 이상해요]** → 할 일 있을 때만 나오는 안내 카드(권한 안 됨·기준 없음·멈춘 항목) → 최근 고친 일 요약 → ── 구분선 "가족·관리용" ── → 기준 상태 상세 + [기준 찍기] → 전체 기록(접힘) → 대기열·데모 설정·장애 주입·키 상태(접힘).
   - P2: 권한이 꺼져 있으면 그 안내를 상태 카드 바로 아래 최우선으로. 켜져 있으면 준비 상태 섹션은 통째로 숨기고 관리 영역에 "✔ 접근성 켜짐 · ✔ 알림 정책 켜짐" 한 줄만.
   - P3: [기준 찍기]를 관리 영역으로 내리고 버튼 문구를 "기준 다시 찍기 (가족이 할 일)"로.
   - 제목 "폰 도우미"는 상태 카드 안 작은 머리글로 넣거나 빼도 됨 (아이콘·상단에 이미 있음).
2. **P4 상단 상태 카드** (난이도 중, 가장 효과 큼):
   - 가로 전체 둥근 카드, 큰 아이콘(✓/! /✕) + 굵은 한 줄 + 보조 한 줄. 3단계: 🟢 "폰이 괜찮아요" / 마지막 확인 시각, 🟡 "확인이 필요해요" / 사유, 🔴 "고치지 못했어요" / "가족에게 연락했어요".
   - 등급 규칙: 빨강=마지막 점검 결과에 FAILED 있음, 노랑=권한 꺼짐/기준 없음/멈춘 항목 있음/마지막 점검 오래됨(24시간)/대기열에 못 보낸 알림, 초록=위 어느 것도 아님.
   - **마지막 점검의 시각·결과 등급을 Store에 저장**해야 앱을 다시 켜도 맞는 상태가 나온다 (지금은 토스트로만 나오고 사라짐). 기존 저장 형식과 호환되게 (필드 없으면 "알 수 없음" 취급).
   - 등급 계산은 Android 없는 순수 함수로 `core/`에 두고 단위 테스트를 붙일 것.
3. **P21·P22 가족·관리용 접기 + P23 데모 표시** (난이도 소~중):
   - 화면 아래 [▸ 가족·관리용 (눌러서 열기)] 한 줄. 누르면 기준 상세·전체 기록·대기열·데모 스위치·통화 기준·장애 주입·키 상태가 펼쳐진다. 펼침 상태는 매번 닫힌 채로 시작 (Store에 저장하지 않음).
   - 여는 방법: **길게 누르기(2초)로 열기** (부모님이 우연히 열기 어려움). 단, 데모 모드가 켜져 있으면 처음부터 펼친 상태로 시작.
   - 데모 임계값이 켜져 있으면 상태 카드 아래에 작은 띠 "데모 모드 (기준 시간이 짧아요)" 표시.
   - `render()`가 전부 다시 그릴 때 펼침 상태가 닫히지 않게 펼침 상태를 필드로 기억할 것 (제안서 P31 참고).
4. **P30 취침 시간 선택기** (난이도 소):
   - 기준 찍기 다이얼로그의 취침 시간 텍스트 입력을 `TimePickerDialog`로 바꾼다. 형식이 틀리면 조용히 기본값으로 저장되던 실기 결함이 같이 해결된다.

## 구현 방식 (제안서 §5 준수)
- **코드 기반 View 유지, Compose·XML 전환 금지.** `Ui.kt`에 도우미 추가: `Ui.card()`, `Ui.bigButton()`, `Ui.statusCard(level, title, sub)`, `Ui.collapsible(title, body)` 정도.
- `render()`를 섹션별 함수(`renderStatusCard()`, `renderActions()`, `renderParentLog()`, `renderAdmin()` 등)로 나눈다. 화면은 하나 그대로.
- 기존 기능은 전부 유지: 동의 다이얼로그, 고치는 중 배너 + [중단] 버튼, 스냅샷 찍기/표시, 멈춘 항목 다시 켜기, 지금 점검하기, 폰이 이상해요(Liner 분류), 고친 기록, 대기열 다시 보내기, 데모 스위치·통화 기준, DEBUG 장애 주입 메뉴, Liner/텔레그램 키 상태 줄.
- 2차·3차(P7 기록 분리, P12 타일 버튼, P25 색 정리, P14 증상 고르기 등)는 **이번에 하지 않는다.**
