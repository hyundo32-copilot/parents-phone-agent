# UI 개선 2차 묶음 구현계획 2부 마무리 (Claude Router 경유 Opus)

## 배경
2부 계획서의 마지막 절(6. 위험과 주의)이 토큰 한도에 걸려 아래 문장 중간에서 끊겼다. 이 문장을 완성하고 6절을 마저 쓴 뒤 계획서를 끝낸다. 앞부분을 반복하지 않는다.

끊긴 부분 (마지막 줄):
```
- **음질과 읽기**
  - `koreanTime`, 숫자, 퍼센트, 영문 약어를 실제로 자연스럽게 읽는지 듣고 확인한다.
  - 어색하면 `forSpeech` 치환표만
```

앞부분에서 이미 다룬 6절 항목 (반복하지 않는다):
- 한국어 TTS 음성 유무 (엔진 차이, `LANG_MISSING_DATA` 시 ttsFailed 카드, 음성 데이터 설치 안내는 범위 밖)

## 쓸 것 (이것만, 짧게)
1. 끊긴 문장을 완성한다.
2. 6절에 남은 위험 항목이 있으면 2~3개만 추가한다 (예: TalkBack 중복 읽기, 결과 카드로 화면이 길어지는 문제, 백그라운드 점검 무음 확인). 이미 쓴 항목은 반복하지 않는다.
3. 마지막에 계획서 전체를 닫는 한 줄(2부 끝)을 붙인다.

## 출력 형식
- 한국어로 작성한 마크다운. 짧게.
