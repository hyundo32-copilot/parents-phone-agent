# UI 개선 2차 묶음 구현계획 2부 이어쓰기 (Claude Router 경유 Opus)

## 배경
바로 앞 요청에서 받은 2부 계획서가 토큰 한도(4096)에 걸려 아래 문장 중간에서 끊겼다. 끊긴 지점부터 이어서 써 준다. 앞부분을 반복하지 않는다.

끊긴 부분 (마지막 줄):
```
- **`speakStatus()`**: `SpeechText.statusCard(...)`로 문장을 만들고 `announcer.speak()`
```

앞부분에서 이미 정해진 결정 (바꾸지 않는다):
- 읽어 주기: 상태 카드 안 [🔊 읽어 주기] 버튼만 둔다. 길게 누르기는 쓰지 않는다.
- 결과 카드 표시 기간: 다음 결과가 생기거나 [확인했어요]를 누를 때까지 유지. 시간 제한 없음.
- 결과 저장: SharedPreferences `last_result`(JSON).
- 점검 끝 음성: 사용자가 직접 시작한 점검 + 앱이 앞에 있을 때만 결과 한 줄을 읽는다.
- TalkBack 켜져 있을 때: 자동 음성은 끄고 `announceForAccessibility`로 대신한다. [읽어 주기] 버튼은 그대로.
- TTS 실패: 결과 카드에 "소리로 읽어 드릴 수 없어요. 화면 글을 봐 주세요."를 INFO로 남긴다.
- 토스트 4종을 모두 결과 카드로 옮기고 `Toast` 사용을 0으로 만든다.
- 신규 순수 파일: `core/ResultNote.kt`(`ResultNotes`), `core/SpeechText.kt`(`koreanTime`, `statusCard`, `forSpeech`).
- `Announcer.kt`: `speak(text)`, `isTalkBackOn(ctx)`, `stop()`. `Ui.kt`: `statusCard`에 `onSpeak` 인자, `resultCard` 신규, `contentDescription` 추가.
