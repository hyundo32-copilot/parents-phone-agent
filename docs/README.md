# 개발 문서

부모님 폰 에이전트("폰 도우미")의 기획서, 설계, 구현·검토, UI 개선, 수정 이력을 모아둔 곳이다.
이 폴더가 개발 문서의 정리본이다. 앞으로 새 문서는 여기에 바로 쓴다.

## 읽는 순서

1. **기획서-설계** — 무엇을, 왜 만드는지
2. **구현-검토** — 1단계 프로토타입을 어떻게 만들었고, 뭐가 문제였는지
3. **UI-개선** — 화면을 어떻게 다듬었는지
4. **수정-이력** — 실기에서 나온 문제를 어떻게 고쳤는지 (날짜순)

## 참고

- 설계 문서(`design-snapshot-restore.md`) §4에는 옛 용어 "심박"이 남아 있다. 현재 용어는 **안부 신호**다.
- `원본출력/`의 JSON은 모델 응답 원본이다. 읽을 때는 같은 이름의 `.md` 문서를 먼저 본다.
- 비밀값(API 키·봇 토큰·채팅 ID)은 이 폴더에 없다. 키는 `local.properties`에 두고, 그 파일은 커밋하지 않는다.
