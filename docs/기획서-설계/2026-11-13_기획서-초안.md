## 1. 누가, 어떤 불편을 겪는가

별도로 사는 연로한 부모님이 쓰는 갤럭시 폰. 가장 잦은 증상은 네 가지다. 문자가 안 온다, 전화가 안 받아진다, 전화가 안 걸린다, 상대가 안 끊으면 본인도 안 끊고 통화를 계속 유지한다.

대부분 원인은 고장이 아니라 "잘못 눌린 설정"이다. 비행기 모드, 무음, 방해금지, 꺼진 알림. 자식이 직접 가서 고쳐주면 되지만, 매번 갈 수 없고 전화로 단계를 따라오게 하는 것도 부모님께는 어렵다. 껐다 켜면 돌아오는 경우도 있지만, 그마저도 매번 부모님이 직접 해야 한다. 문제는 진단이 아니라 "정상 상태로 되돌리기"다.

## 2. 에이전트는 어떻게 해결하는가

**기준 스냅샷 + 자동 복원.** 자식이 폰을 제대로 세팅한 상태에서 정상 설정값을 스냅샷으로 찍어 폰 안에만 저장한다. 에이전트는 하루 2회 주기적으로 기준과 비교하고, 벗어난 항목을 되돌린다. 정상값은 하드코딩하지 않는다. 부모님별 실제 상태가 기준이다.

**등급을 나눠 안전하게 되돌린다.** A등급(무음·볼륨·방해금지·비행기 모드·Wi-Fi·데이터·전화/문자 앱 알림)은 사전 승인된 항목이라 즉시 복원하고, 복원 전후를 음성 한 줄로 알린다. B등급은 부모님 음성 확인을 거친다. C등급은 자동 복원을 하지 않고 자식에게 넘긴다. 같은 수정은 한 증상당 1회, 총 3회까지만 시도하고, 같은 이탈이 3일 연속이면 의도된 변경으로 보고 멈춘다. 수정 중에는 "지금 고치는 중" 표시와 큰 중단 버튼을 항상 둔다. 문자·통화 내용, 사진, 연락처 전체, 비밀번호는 수집하지 않는다.

**결과는 카드와 음성으로 바로 확인한다.** 점검 결과는 화면의 결과 카드 한 장에 보여주고, [읽어 주기] 버튼을 누르면 음성으로 읽어준다. 토스트 알림은 쓰지 않는다.

**안부 신호.** 하루 1회 09:00에 "정상" 신호를 자식에게 텔레그램으로 보낸다. 예정보다 1시간 이상 늦으면 "지연됨"으로 표시한다. 신호가 36시간 끊기면 에이전트 권한이 꺼졌거나 폰에 문제가 있는 것으로 보고 자식이 직접 확인한다. 침묵 자체가 알림이다.

## 3. Liner API 사용처 (검증 완료)

조작 결정은 규칙 엔진만 하고, Liner 모델 API(`liner-mark-1.0`)는 두 곳에만 쓴다. 2026-11-13 실제 키로 호출해 확인했다.

1. **증상 분류** — 부모님이 "문자가 안 와"라고 하면 `SMS_NOT_RECEIVED`로 분류해 어떤 점검을 할지 정한다. 분류가 틀리거나 모르면 일반 점검으로 돌아간다.
2. **에스컬레이션 요약** — 복원을 시도한 내역과 전후 수치를 한국어로 요약해 자식에게 텔레그램으로 보낸다. 요약문은 원문에 없는 내용을 지어내지 않는다.

망이 끊기면 Liner를 거치지 않고 규칙 엔진 원문만으로 동작하고, 망이 돌아오면 대기열에 둔 메시지를 한 통만 보낸다.

## 4. 1단계 프로토타입 — 만든 것

스냅샷 찍기·주기 비교·A등급 자동 복원·에스컬레이션·증상 버튼·안부 신호·장애 주입 메뉴(디버그용)를 구현했다. 화면도 부모님 기준으로 다듬었다. 기록을 부모님용 요약과 가족용 전체 로그로 나누고, 큰 타일 버튼과 결과 카드·[읽어 주기]를 넣었다. 단위 테스트 253개 전부 통과, 빌드 성공, APK 약 1.21MB. 소스코드는 GitHub 비공개 레포에 있고(제출 시 공개 전환 또는 zip), API 키·텔레그램 토큰은 코드에 넣지 않고 `.env`(local.properties)로 분리했다. README에 실행 방법과 Liner 사용처를 적었다.

실기(Galaxy Z Flip5, 2026-11-15~17)에서 확인한 것: 방해금지·Wi-Fi·비행기 모드·진동 복원, 벨소리 무음 → 소리 복원(11/17 수동 점검), 안부 신호 11/15 09:00 지연 도착, 결과 카드·[읽어 주기]·복사 버튼. 알려진 한계: 점검 후 앱 복귀가 간헐적으로 안 돼 마지막 스탭으로 미뤘고, 11/18 08:00 예약 점검 벨소리 복원은 재확인 예정이다. 2단계(장시간 통화 30분 감지·B등급 확인·SMS 폴백)와 3단계(Shizuku 연동)는 다음 단계다.

## 5. 다른 조직·직무로의 확장

같은 구조가 그대로 통하는 곳이 있다. 요양시설·복지관의 공용 폰, 매장·현장의 공용 단말기처럼 "한 사람이 제대로 세팅해두고, 여러 사람이 만지는" 기기다. 기준을 찍어두고 벗어나면 되돌리는 방식은 기종·직무가 바뀌어도 같고, 에스컬레이션 받는 사람만 바꾸면 된다. 가족 돌봄에서 시작해 돌봄 시설과 현장 공용 기기로 넓힐 수 있다.
